# TEST-PILOT Privacy Notice — HPE EdTech 2569

## Status
DRAFT FOR TEST-PILOT ONLY — not a production privacy notice.

## Purpose
This TEST-PILOT uses only the minimum data needed to test:
- registration
- attendance/check-in
- pre-test and post-test
- satisfaction survey
- workshop evidence
- E-Certificate eligibility, issuance and verification

## Data categories
- name and title
- email
- participant role
- attendance status
- assessment responses and scores
- satisfaction responses
- workshop evidence submitted by the participant
- certificate number, issuance status and verification token

## Use limitation
Data collected in this TEST-PILOT must not be reused for unrelated purposes and must not be treated as production programme records.

## Certificate
All certificates in this phase must display:
- TEST / รุ่นทดสอบ
- test certificate numbering
- signer: ผู้ช่วยศาสตราจารย์ ดร.เกษม ชูรัตน์

## Retention
TEST-PILOT retention end date: 24 November 2026.

This date is a controlled test setting for the pilot and is not a final institutional retention policy.

## Access
Access is limited to the TEST-PILOT participant workflow and explicitly bound seminar owner/admin accounts. Direct anonymous/authenticated table access remains denied.

## Release boundary
Before production use, this notice, legal basis, retention period, participant communication, and institutional authorization must be reviewed and approved separately.
