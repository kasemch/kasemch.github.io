## Calendar policy

Google Calendar is the operational source of truth for authenticated event management. This public GitHub Pages projection remains intentionally separate and fail-closed: it does not automatically expose private calendar contents.

Only events explicitly approved for public visibility may be projected into this page. Private teaching schedules, meetings, deadlines, attendee information, meeting links, restricted notes, and personal events remain outside the public build unless deliberately published.

If no event has been approved for public display, the calendar shows an empty state instead of demonstration or inferred schedule data.
