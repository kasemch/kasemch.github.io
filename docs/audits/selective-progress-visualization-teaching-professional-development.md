# Selective Progress Visualization Audit — Teaching & Professional Development

## Decision
- Teaching: add an explanatory Teaching Evidence Path because the public page already contains an evidence-backed sequence: Course → Teaching → Assessment → TQF5 → Verification → Improvement.
- Professional Development: retain the credential card/filter dashboard. The registry represents independent credentials with completion and validity dates, not a single evidence-backed progression pipeline.

## Teaching interpretation rule
The Teaching Evidence Path is an explanatory architecture only. It is not a completion score and does not imply that every course has complete evidence at every stage. Official MR30 offering status remains authoritative and is not overridden by quality-document existence.

## Professional Development interpretation rule
Do not infer a chronological or hierarchical professional-development journey from credential dates alone. Add a progress visualization only if a future public-safe evidence source explicitly defines a programme sequence or competency pathway.
