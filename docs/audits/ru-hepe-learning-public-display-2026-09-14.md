It must not be described as the official GitHub organization of Ramkhamhaeng University unless formal institutional designation is independently verified.

## Disclosure boundary

Public pages may display:
- organization name and public GitHub URL;
- public repository names and public repository URLs;
- high-level educational purpose of each public repository.

Public pages must not expose:
- confidential HEPE governance architecture;
- private repositories or private repository metadata;
- credentials, tokens or secrets;
- student-identifiable information;
- claims of official university authority not supported by an authoritative institutional source.

## Implementation rule

Public organization metadata is maintained in `/_data/ru_hepe_learning.yml` so future public repositories can be added in one controlled source rather than duplicated across pages.
