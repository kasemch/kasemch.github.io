# Research Status + Academic Textbook Writing — Visual Options

Status: Design reference only. No unpublished manuscript text or controlled evidence is rendered by this document.

## Hybrid Wide baseline
The Research Project Detail page uses a hybrid width hierarchy:
- Hero / project summary: near-full desktop width.
- Current gate / lifecycle / outputs: wide content band.
- Evidence matrix: full content width with horizontal overflow only when required.
- Validation / evidence narrative / boundary note: readable-width column.

## Six status-reporting patterns

### Option 1 — Step Timeline
A numbered milestone sequence with Verified / Active / Not publicly confirmed states.
Best for: formal lifecycle traceability.
Strength: easiest to understand and audit.
Risk: long projects become visually tall.

### Option 2 — Stage Rail
A horizontal desktop rail showing major stages, with the current stage enlarged and completed stages checked.
Best for: quick executive overview.
Strength: compact and visually modern.
Risk: requires careful mobile stacking.

### Option 3 — Kanban Status Board
Three columns: Completed / In progress / Next gate.
Best for: active workstream reporting.
Strength: immediately shows what is moving now.
Risk: less suitable as a strict chronological record.

### Option 4 — Progress Rings + Gate Cards
A small set of progress indicators for Evidence readiness, Instrument development, Ethics/public gate, Outputs, and Publication binding, followed by explanatory cards.
Best for: dashboard-style monitoring.
Strength: strong executive scanability.
Risk: numeric percentages must never be invented; use categorical states unless evidence supports a percentage.

### Option 5 — Milestone Map
A visual path of connected milestone nodes grouped into phases such as Foundation, Protocol, Instrument, Data, Analysis, Publication.
Best for: storytelling and complex multi-phase research.
Strength: visually engaging and good for explaining dependencies.
Risk: more visual complexity and slightly higher maintenance.

### Option 6 — Evidence Ladder
Each stage is shown as a vertical ladder with three layers: Stage → Evidence → Public output. Only verified evidence allows the next rung to appear as verified.
Best for: evidence-first academic governance.
Strength: directly communicates why a stage is considered verified.
Risk: denser than a simple timeline.

## Recommended research pattern
Recommended default: **Option 6 — Evidence Ladder**, combined with a compact Option 2 Stage Rail at the top.
Reason: the site is explicitly evidence-first, so project status should communicate not only what stage exists but what public-safe evidence supports that status.

## Academic Textbook Writing — public-safe status concept

The textbook area should be visually distinct from research but use the same status language.

### Proposed card architecture
Each textbook card should show:
- Textbook / course title.
- Public-safe development stage.
- Current focus.
- Evidence readiness category.
- Next verified milestone.
- Last reviewed date only when independently supported.
- No manuscript text, unpublished chapters, private source links, committee comments, signature/approval text, or unsupported completion claim.

### Suggested public-safe projects

#### HED3505 — School Health Program & Evaluation
Public-safe stage: **Pre-writing / Conceptual Architecture**
Current focus: course alignment, conceptual structure, and evidence architecture.
Next public-safe milestone: verified evidence architecture and chapter structure readiness.
Do not claim chapter drafting has begun unless a later verified record supports it.

#### HED3502 — Drugs and Substance Abuse
Public-safe stage: **Blueprint / Evidence Verification**
Current focus: curriculum verification, academic landscape, conceptual architecture, and evidence matrix preparation.
Next public-safe milestone: evidence matrix and source verification sufficient to open chapter writing.
Do not claim official submission, institutional approval, or completed textbook status without authoritative evidence.

## Recommended textbook display pattern
Use a **Book Journey Board** with four stages:
1. Align — curriculum / course evidence.
2. Architect — concept, chapter structure, author contribution.
3. Evidence — source matrix and citation readiness.
4. Write — chapter drafting and editorial development.

For each textbook, highlight only the latest verified stage and the next gate. Future stages stay visually muted and must not appear completed unless verified.

## Possible placement
Preferred placement: a dedicated public page `/academic-writing/` linked from Professional Development or Innovation & Projects, plus a compact two-card summary on the Home page or Academic Dashboard.
Alternative placement: a new "Academic Writing" section inside the existing project-status ecosystem, but not inside Research Project Detail because textbooks are scholarly development projects rather than research lifecycle records.

## Public disclosure boundary
Display only high-level project name, theme and development stage. Do not publish manuscript text, unpublished chapters, private draft files, committee/internal review correspondence, confidential source links, or claims of submission/approval without authoritative public evidence.
