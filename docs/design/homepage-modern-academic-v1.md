# Homepage Modern Academic Hero v1.0

Status: APPROVED VISUAL BASELINE — implementation branch only; not production.

## Design direction
- Modern Academic Hero, not a generic developer portfolio.
- Palette: Navy / White / restrained Gold.
- Emphasis: academic credibility, research, teaching, curriculum & quality assurance, and responsible digital innovation.
- Preserve the existing Academic Pages/Jekyll architecture and public evidence boundaries.

## Homepage information architecture
1. Hero — verified identity, institutional role, portrait, concise academic proposition, primary CTAs.
2. Expertise — Health & Physical Education; Curriculum Development; Quality Assurance / AUN-QA; AI in Education.
3. Academic roles — Teaching; Research; Curriculum Chair; AUN-QA; Digital Innovation; Community Service, only where publicly supportable.
4. Featured Work — Research; Teaching & Learning; Curriculum & QA; Digital Innovation.
5. Research & Innovation — public-safe active projects sourced from repository evidence.
6. Teaching — verified courses and teaching evidence.
7. Curriculum & Quality Assurance — verified programme and QA evidence.
8. Academic Outputs — derive counts from structured verified repository data; no invented metrics.
9. Current Projects — public-safe status and links only.
10. Footer — academic identity, navigation, verified public contact/social links.

## Evidence rules
- No invented publication, project, course, impact, or metric counts.
- Dynamic counts must be derived from repository data where possible.
- Private/confidential project material must not be exposed.
- Institutional authority claims require explicit public evidence; project-controlled artefacts must remain labelled accordingly.

## Implementation constraints
- Responsive desktop/tablet/mobile.
- Semantic HTML and keyboard-accessible interactions.
- WCAG-oriented contrast/focus/heading review.
- Preserve existing URLs where possible.
- SEO/Open Graph/structured metadata must remain evidence-grounded.
- Optimize images and avoid layout shift.

## Production gate
Implementation and review may proceed on this branch. Merge/deployment to the public default branch remains a separate production Human Gate.
